# 🍕 Hostel De Pizza

## Laravel Food Ordering System

Hostel De Pizza is a web-based food ordering application built with Laravel and MySQL.

This project provides a complete ordering workflow with customer and administrator features, including product management, shopping cart, order processing, and user management.

---

## 🚀 Features

### 👤 Customer

- User authentication
- Browse pizza products
- Search and filter products
- Product details
- Shopping cart
- Order management
- Order history
- Product review and rating


### 🛠️ Admin

- Admin dashboard
- Manage products
- Manage categories
- Manage users
- Manage orders
- Monitor customer feedback
